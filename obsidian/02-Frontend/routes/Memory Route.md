# Memory Route

> `/memory` — agent long-term memory: trade lessons + reflections.

## Source

- `frontend/src/routes/memory/index.tsx`

## How it works

`requireAuth()` guard. Lists `Lesson` documents generated by the `TradeLearner`
service after closed trades. Each lesson shows the source trade, the extracted
insight, the embedding-derived tags, and the knowledge-graph edges
(`LEARNED_FROM`, `APPLIES_TO`).
