# TanStack File-Based Routing

> The route tree (`routeTree.gen.ts`) is auto-generated by the `@tanstack/router-plugin` Vite plugin — no manual `router-cli generate` step.

## Source

- `frontend/vite.config.ts`
- `frontend/src/routes/`

## How it works

`vite.config.ts` registers `tanstackRouter({ target: "react", autoCodeSplitting: true })`,
which scans `src/routes/`, generates a typed route tree, and code-splits each
file into its own chunk. File naming follows TanStack conventions: `__root.tsx`
is the root layout, `index.tsx` inside a folder maps to that folder's route,
files prefixed with `-` (e.g. `-guards.ts`) are excluded from the tree.
`autoCodeSplitting` means every leaf route gets its own dynamic-import boundary,
so `navigationPreload.ts` can prefetch chunks on hover.

## Depends on

- `@tanstack/react-router`
- `@tanstack/router-plugin`

- [[Root Route]]

## Gotchas

- Don't commit changes to the generated `routeTree.gen.ts` by hand — it regenerates on every dev/build.
