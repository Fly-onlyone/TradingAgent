# Zustand

Small, hook-based state management library for React. Used for all client-side state in this frontend — stores live in `frontend/src/store/xxxStore.ts` and use the devtools middleware. Context7 ID: `/pmndrs/zustand`. Typical pattern: `useUIStore((s) => s.uiScale)`.
