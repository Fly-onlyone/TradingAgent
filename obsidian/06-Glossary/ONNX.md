# ONNX

Open Neural Network Exchange — a runtime and file format for running ML models cross-platform without the original training framework. Used here as the backend for [[sentence-transformers]] running [[nomic-embed-text-v1.5]] — gives fast CPU inference without needing PyTorch at runtime.
