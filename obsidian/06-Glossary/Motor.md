# Motor

Async Python driver for MongoDB. Underlies [[Beanie ODM]]. Used directly in the backend for aggregation pipelines via `get_pymongo_collection()` — the deprecated `get_motor_collection` is avoided. Context7 ID: `/mongodb/motor`. See [[Motor Async Driver]].
