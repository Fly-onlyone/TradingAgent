# TanStack Router

File-based, type-safe React router. Routes live as files under `frontend/src/routes/`. The `@tanstack/router-plugin` in `vite.config.ts` auto-generates the route tree at dev and build time — manual `router-cli generate` is usually unnecessary. Context7 ID: `/TanStack/router`.
