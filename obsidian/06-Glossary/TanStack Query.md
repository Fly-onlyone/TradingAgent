# TanStack Query

Async state manager (formerly React Query) — handles fetching, caching, invalidation, and optimistic updates for server data. This app centralizes query options in `frontend/src/api/queryOptions/admin.ts` with shared `ADMIN_STALE_TIME` and `ADMIN_GC_TIME` constants. Context7 ID: `/TanStack/query`.
