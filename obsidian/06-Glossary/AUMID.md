# AUMID

App User Model ID: Windows identifier used to group taskbar entries and look up the title icon on toast notifications. Current working value in this app: `TradingAgent` (configured in `backend/app/services/desktop_notify.py`). The NSIS installer sets it on the Start Menu shortcut from `tauri.conf.json` `identifier`. See [[AUMID Configuration]] for the full rules.
